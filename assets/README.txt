README — assets folder

This folder should contain the image files used by the site. Add your images with the exact filenames below.

Required files (place in assets/):
- logo.png         (Image 1 — your logo)
- logo-icon.png    (favicon 32×32 — you can copy logo.png and resize to 32×32)
- soap_box1.jpg    (Image 2)
- soap_box2.jpg    (Image 3)
- collage.jpg      (Image 4 — banner / collage)

Once you add the images, GitHub Pages will show the full site. If you want me to upload the image files for you, reply and attach them or grant access.
